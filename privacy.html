Privacy policy

rclone (personal Google Drive client), operated by Jacob Nye for personal use. Last updated 31 October 2026.

Who uses this app

Only its owner, to manage the owner's own Google Drive. It is not offered to anyone else.

Google user data the app accesses

With the owner's consent, rclone uses Google OAuth to read the owner's Drive file listings, metadata and checksums (drive.readonly) and to create and update the backup files it uploads (drive.file).

How the data is used

Only to copy the owner's files to the owner's Drive, copy them back, and verify transfers by comparing file sizes and checksums. The data is not used for advertising, profiling, analytics, or training any model.

Storage

The OAuth tokens and any transfer logs stay on the owner's own computer, in rclone's local configuration and log files. The app runs no server and keeps no copy of Google user data anywhere else.

Sharing

Google user data is not sold, shared with, or transferred to any third party.

Revoking access

Access can be removed at any time at myaccount.google.com/connections, which immediately invalidates the app's tokens.

Limited Use

This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
