rclone (personal Google Drive client)

A personal-use OAuth client operated by Jacob Nye (GitHub: thecobb).

What this app is

This Google Cloud OAuth client lets the open-source file sync tool rclone, running on its owner's own computer, back up files to the owner's own Google Drive and check that every uploaded file arrived intact by comparing checksums.

It is not a public service. It has one user, its owner, and nobody else is invited to sign in to it.

What it accesses

  • Google Drive, read-only (drive.readonly): lists the owner's Drive and reads file sizes and checksums so backups can be verified.
  • Files the app creates (drive.file): uploads backup files and can change only files it created itself.

Everything runs locally in rclone on the owner's computer. There is no server and no third party in between.
